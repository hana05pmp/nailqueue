# Nail Queue Manager

Build a complete responsive web application for a Nail Salon Queue Management System.

The main purpose is to manage customers waiting for nail salon services and analyze queue performance.

Create these pages:

CUSTOMER SIDE

1. Home

2. Services

3. Join Queue

4. My Queue

5. Queue History

Customer functionality:

- Select a nail service

- Enter customer name

- Join the queue

- Receive a unique queue ticket number

- View current queue position

- View number of customers ahead

- View estimated waiting time

- View current serving ticket

- Cancel queue

- View completed/cancelled queue history

STAFF SIDE

1. Staff Login

2. Queue Dashboard

3. Services Management

4. Analytics Dashboard

Staff functionality:

- View waiting customers

- Call next customer

- Start service

- Complete service

- Skip customer

- Add walk-in customer

- Manage nail services

- View queue statistics

QUEUE STATISTICS

- Total customers

- Waiting customers

- Customers served

- Cancelled customers

- Average waiting time

- Average service time

- Maximum queue length

Use React and TypeScript.

Use localStorage for data persistence.

Do NOT use MongoDB.

Do NOT use Firebase.

Do NOT use Supabase.

Do NOT create an external backend.

Use mock/seed data so the application can be demonstrated immediately.

Create a clean, professional nail salon design.

Make the application responsive for laptop and mobile.

Build reusable components and keep the code organized.
